# Community conduct

properpcloud is a technical collaboration space. Be respectful, specific, and
constructive. Criticize code and decisions, not people. Respect privacy,
identity, accessibility needs, and different experience levels.

Harassment, threats, discriminatory conduct, sexualized attention, sustained
disruption, and deliberate exposure of private information are not tolerated.
Maintainers may edit, hide, lock, or remove content and participation to
protect the project and its community.

Report conduct issues privately through the repository owner's GitHub profile
or private security/contact channel.
