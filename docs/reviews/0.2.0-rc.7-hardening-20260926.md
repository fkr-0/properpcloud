## Findings fixed

1. **Playback failures exposed implementation-oriented Media3 error names.**
   - Added stable, actionable user messages for network loss, permission denial, missing media, expired/denied HTTP access, and corrupt/unsupported decoding failures.
   - Provider paths, exception messages, and signed capability details are not surfaced.

2. **Source/library failures could surface raw provider exception text or silently fail.**
   - Source-facing operations now classify permission, connectivity/IO, transient stream-resolution, and item-unavailable failures into redacted recovery guidance.
   - Containing-folder and bookmark navigation now report disconnected, unavailable, or permission-failure states instead of silently returning.
   - Failed library refresh preserves the last visible node list and exits refreshing state with an actionable error.

3. **Audiobook resume persistence omitted the active playback speed from progress checkpoints.**
   - Playback speed is now included in checkpoint observations, with a regression test proving resume position, duration, chapter identity, and speed persist together.

4. **New RC regression tests were themselves unstable.**
   - A plain-JVM playback-message test constructed `PlaybackException`, which touches Android `SystemClock`; it now tests the pure error-classification helper directly.
   - The library-refresh test assumed DataStore startup completed synchronously; it now waits for the observable initial library state and refresh completion.
   - `PlayerRegistryTest.kt` triggered an Android Lint FIR/UAST analyzer crash on nested function literals; equivalent explicit helpers/method references preserve coverage while allowing lint to complete.

## Edge-case coverage

- Network-disconnected/transient stream resolution: queue is preserved and failure is surfaced for retry/reconnect.
- Terminal corrupt/unsupported/unavailable item: bounded omission/skip behavior remains covered without cascading through transient failures.
- Permission denied during browsing/navigation: redacted actionable UI message.
- Library refresh failure: last-good visible content retained.
- Audiobook checkpoint/resume: stable chapter identity, position, duration, and speed persisted.
- Remote player discovery/reconnect/removal: provider target degradation/unavailability and local-player authority remain covered.
- Interrupted pCloud metadata staging downloads: regression coverage now proves a partially written destination is deleted when transport fails; existing implementation also validates size/hash/revision. General offline media pinning remains intentionally deferred beyond this RC.
