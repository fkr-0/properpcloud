# properpcloud 0.1.9 Linux compatibility evidence matrix

This matrix separates immutable automated evidence, observations available on the current
host, and checks that genuinely require another desktop session or protected account.
A failed or pending required cell remains visible and blocks promotion to `0.2.0` unless
the maintainer explicitly accepts a narrowly documented exception.

## Long-playback soak

The credential-free `desktop-resilience-soak` exercises repeated pause/resume, relative and
absolute seek, durable checkpoints, one forced mpv process exit, explicit restart, stable
queue identity, bounded drift, and bounded memory growth. Its duration is controlled by
`PROPERPCLOUD_SOAK_SECONDS` up to four hours.

The final provider soak still requires protected media and must retain a four-hour run with
one genuine capability expiry, one suspend/resume cycle, and redacted diagnostics. Protected
provider media, tokens, signed URLs, and response bodies must never enter the evidence packet.

The canonical promotion state is `docs/reviews/0.2.0-promotion-matrix.yml`; use
`python3 scripts/validate-020-readiness.py --pre-tag` before tag creation and `--strict`
after exact-tag package verification, before publication.
