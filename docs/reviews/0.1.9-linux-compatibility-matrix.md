# properpcloud 0.1.9 Linux compatibility evidence matrix

This matrix separates automated evidence from observations that require real desktop
sessions. A blank or failed cell blocks promotion to `0.2.0`; it must not be rewritten
as a general compatibility claim.

## Automated baseline

| Gate | Command | Required evidence | Status |
|---|---|---|---|
| Forced player exit and recovery | `make desktop-crash-recovery-smoke` | fixed failure state, zero automatic restarts, stable queue identity, resume within 5 s | automated |
| Clean packaged profile | `make desktop-clean-profile-smoke` | isolated HOME/config/data/cache/state and successful mpv/SQLite smoke | automated |
| AppImage package | `make desktop-appimage-smoke PREBUILT_DESKTOP_IMAGE=1` | private extraction, reviewed launcher, embedded version, clean-profile mpv/SQLite smoke | automated locally; repeat on immutable tag |
| Flatpak package | `make desktop-flatpak-smoke PREBUILT_DESKTOP_IMAGE=1` | temporary non-destructive install, isolated app state, MPRIS and host mpv IPC | automated locally; repeat on immutable tag |
| Release artifact graph | `python3 scripts/release_graph.py ...` | exact version/tag/commit, filenames, sizes, SHA-256 graph, no secret fields | automated |
| Arch recipe preparation | `python3 scripts/render-arch-pkgbuild.py ...` | immutable HTTPS source and calculated SHA-256; no `SKIP` | automated preparation only |

## Accessibility matrix

| Check | Acceptance condition | Status |
|---|---|---|
| Keyboard-only operation | library, queue, player, account, and restart controls usable without pointer | pending |
| Focus order | visible deterministic focus; no keyboard trap | pending |
| 200% text | no clipped critical labels or unreachable actions at 1280×820 | pending |
| High contrast | controls and selected/current states remain distinguishable | pending |
| Non-drag queue control | select, move up/down, remove, and play are keyboard reachable | pending |

## Long-playback soak

Minimum retained run: four hours with pause/resume, absolute and relative seek, one
forced mpv exit, one suspend/resume cycle, and at least one provider stream-link refresh.
Record queue identity, checkpoint drift, restart count, memory growth, and redacted
diagnostics. Protected provider media must never be attached to the evidence packet.
